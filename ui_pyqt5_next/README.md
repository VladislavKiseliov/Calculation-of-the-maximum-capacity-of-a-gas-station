# PyQt5 UI Prototype

Новый интерфейс создан в отдельной папке, без изменения текущего tkinter-приложения.

## Запуск

```bash
pip install PyQt5 pyqtgraph
python ui_pyqt5_next/main.py
```

## Что реализовано

- Sidebar + дерево объектов (QTreeView)
- Dashboard с критическими зонами и графиком
- Модульные вкладки (газ/трубы/регуляторы/котельные)
- Валидация полей на лету (подсветка некорректного ввода)
- Инструментарий: справочники + сравнение текущих/рекомендуемых параметров
- SVG иконки для save/import/calc

## Примечание

Это стартовый каркас нового UI. Он готов для поэтапного подключения к текущим application/core сервисам.
